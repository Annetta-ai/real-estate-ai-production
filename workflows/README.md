# Production Workflows

Documented workflows for transforming architectural CGI and source images into real-estate marketing assets.

## Core workflow

1. Review source files and project requirements.
2. Prepare architectural and creative references.
3. Define preservation constraints.
4. Develop and test prompts.
5. Produce controlled image variations.
6. Complete image quality control.
7. Generate cinematic video from approved images.
8. Complete frame-by-frame video review.
9. Export, document, and archive approved assets.

Every production must retain its source files, prompts, settings, versions, and approval status.
