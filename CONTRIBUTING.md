# Contributing

Contributions to Real Estate AI Production are welcome.

## Ways to contribute

- Add or improve prompt templates.
- Document production workflows.
- Expand quality-control checklists.
- Submit non-confidential example projects.
- Propose AI agents and open-source tools.
- Report errors or unclear documentation.

## Contribution requirements

- Preserve the project’s real-estate and architectural visualization focus.
- Use clear, practical, and tool-agnostic instructions.
- Do not include confidential client information or unlicensed assets.
- Clearly label conceptual architectural content.
- Document tools, models, settings, and limitations.
- Follow the existing Markdown structure and terminology.

## Submitting changes

1. Create a dedicated branch.
2. Make one focused set of changes.
3. Explain what was added or improved.
4. Confirm that all links and Markdown formatting work.
5. Submit a pull request for review.

By contributing, you agree that your contribution may be distributed under the project’s MIT License.
