# Prompt Library

Reusable prompt templates for real-estate AI production.

## Available templates

- CGI → Photorealistic Image
- Image → Cinematic Video
- Luxury Interior Visualization
- Luxury Exterior Visualization

## Usage

1. Select the template that matches the production task.
2. Replace bracketed fields with project-specific information.
3. Clearly define what may change and what must remain unchanged.
4. Record the tool, model, settings, source asset, and version.
5. Apply the relevant quality gate before approval.

All prompts must preserve approved architecture, geometry, materials, camera perspective, and property features.
