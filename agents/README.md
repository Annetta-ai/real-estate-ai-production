# AI Agents

Planned agents for supporting repeatable real-estate AI production tasks.

## Agent roles

- **Asset Intake Agent:** Organizes CGI, plans, references, project requirements, and filenames.
- **Prompt Agent:** Creates structured prompts using approved inputs and preservation constraints.
- **Image QA Agent:** Checks geometry, perspective, materials, scale, reflections, and AI artifacts.
- **Video QA Agent:** Detects flicker, morphing, texture drift, unstable lines, and unintended movement.
- **Delivery Agent:** Prepares approved assets in the required formats, resolutions, and naming structure.

## Operating rules

- Agents may organize inputs, prepare drafts, run checks, and flag issues.
- Agents must not invent property features or approve architectural changes.
- Human review is required before client delivery or publication.
- Every output must retain its source, prompt, model, settings, and version history.
